Project 1 - Foundational Analyses using Multiple-Choice Response Data from an Achievement Test

Introduction

In this project, we will be analyzing the Homeostasis Concept Inventory (HCI) (McFarland et al. 2017), which is a 20-item multiple-choice test designed to measure undergraduate students’ understanding of the homeostasis concept in physiology. The HCI was developed through an iterative process which involved identifying common student misconceptions through think-aloud interviews and expert feedback. Distractors were then developed based on these misconceptions.

The dataset HCIdata is part of the {ShinyItemAnalysis} R package (Martinková and Hladká 2023) and contains N=669 observations which were collected as part of the validation process for the final version of the HCI. Notably, the dataset contains the unscored item responses, which allows for distractor analysis, as well as matching variables such as gender and minority membership, which allows for differential item functioning (DIF) analyses.

The HCIdata dataset contains 49 variables. The first 20 variables (1-20) are the unscored item responses, which are recorded as capital letters (e.g. “A”, “B”, “C”). The next 20 variables (21-40) are the scored item responses which are recorded as “0” or “1”. The next variable (41) is the total/sum score. The last 8 variables (42-49) are demographic variables including gender, plans to major in the life sciences, class level/year in college, ethnicity, minority membership, English as the student’s first language, course type, and type of institution. A complete description of this dataset can be found in the documentation for the {ShinyItemAnalysis} package and additional information can also be found in the validation study for the HCI.

Classical Reliability Analysis

The most common form of reliability that is analyzed in practice is internal consistency, which is typically estimated and reported using Cronbach’s alpha. Internal consistency can be informally defined as the extent to which the items correlate with one another and thus appear to be measuring the same thing. This informal definition raises a natural question: how is internal consistency a measure of reliability? Internal consistency seems to be about the consistency of items within an instrument, while reliability seems to be about the consistency of scores obtained when repeated measures of the same instrument are taken. This raises a perhaps even more fundamental question: how can the reliability of an instrument be meaningful without requiring repeated measures?

These questions can be answered by examining the assumptions of the classical test theory (CTT) framework. The core component of the CTT framework is the classical true score model, which states that a single observed score \(X\) can be decomposed into a true score and an error score:

\[X=T+E\] Where the true score \(T\) is defined as the expectation of the hypothetical distribution of observed scores if the experiment could be independently replicated infinitely many times, which is sometimes called the propensity definition of the true score:

\[T=E[X]\]

From this definition of true score, it follows that the error score does not bias the true score and does not covary with the true score:

\[E[E]=0\] \[Cov[T,E]=0\] This is because:

\[E=X-T\] \[E[E]=E[X-T]\] \[=E[X]-E[T]\] \[=T-T\] \[=0\]

The proof that \(Cov[T,E]=0\) is more complicated and an abbreviated version is shown here.

\[Cov[T,E]=E[TE]-E[T]E[E]\] \[\text{it can be shown that} \; E[TE]=0\] \[=0-T(0)\] \[=0\]

It then follows that the variance of the observed scores can be decomposed into the true score variance and the error score variance:

\[Var[X]=Var[T]+Var[E]\]

This is because:

\[Var[X]=Var[T+E]\] \[=Var[T]+Var[E]+2Cov[T,E]\] \[=Var[T]+Var[E]\]

The reliability coefficient can then be defined conceptually as the ratio of the true score variance to the observed score variance:

\[Rel[X] = Cor^2[X,T] = \frac{Var[T]}{Var[X]} = \frac{Var[T]}{Var[T]+Var[E]}\]

The propensity definition of the true score and the conceptual definition of reliability are the two basic definitions of the classical true score model. However, in its current form, the classical true score model is very limited in its utility. The issue is that, as hinted at earlier, the model only explains a single measurement at a time, which could be a single item score or a single test score. In other words, the model can only explain a single random variable X at a time; there are no subscripts for X, T, or E.

This is a problem because there is, in fact, no way to estimate reliability under the classical true score model as defined thus far. The model is unidentified, since there is only one observed variable (X) and two unknowns (T and E). To resolve this issue, multiple measurements are needed, which may either be multiple item scores from one individual, or multiple test scores from a group of individuals. Given multiple measurements, the problem then becomes that of determining how the measurements need to relate to each other so that they can be combined in useful ways.

First, the assumption of local independence is almost always made. This assumption states that, given the true score(s), the observed scores are conditionally independent. Notably, this assumption provides the following useful result, which is that the errors between two distinct measurements do not covary. This result is very useful because many estimation methods used in CTT rely on the observed covariances between observed scores. These computations would be intractable if the covariances between error scores could not be set equal to zero.

\[Cov[E_i,E_j]=0, \; \text{for items} \; i \neq j\]

Next, there are additional assumptions made about (1) how the true scores between measurements relate to each other, and (2) how the error variances between measurements relate to each other. Here, there are four sets of additional assumptions which are nested within each other: parallel, tau-equivalent, essentially tau-equivalent, and congeneric measurements.

The assumption of parallel measurements states that all measurements have the same true score \(T\) and the same error variance \(\sigma^2_E\). The assumption of parallel measurements is the strictest because it implies that all measurements are fully interchangeable. Statistically, there is no way to tell them apart. Under these conditions, the CTT model becomes:

\[X_i=T+E_i, \; \text{where} \; Var[E_i]=\sigma^2_E \; \text{for all} \; i\]

The assumption of tau-equivalent measurements is slightly weaker by allowing the error variance to differ between measurements. The CTT model becomes:

\[X_i=T+E_i, \; \text{where} \; Var[E_i] \; \text{can differ across i}\]

The assumption of essentially tau-equivalent measurements is weaker still by allowing the true scores to differ from a common true score \(T\) by some additive constant between measurements. The CTT model becomes:

\[X_i=a_i+T+E_i, \; \text{where} \; Var[E_i] \; \text{can differ across i}\]

Lastly, the assumption of congeneric measurements is the weakest by allowing the true scores to differ from a common true score \(T\) by some linear transformation of \(T\). The CTT model becomes:

\[X_i=a_i+\lambda_iT+E_i, \; \text{where} \; Var[E_i] \; \text{can differ across i}\]

It can be shown that under the conditions of essential tau-equivalence or stricter, the internal consistency of measurements defined by Cronbach’s alpha is equivalent to the reliability of measurement defined conceptually as the ratio of true score variance to observed score variance. Additionally, it can be shown that under the weaker conditions of congeneric measurements, Cronbach’s alpha is a lower bound of the reliability of measurement.

To conclude the brief theoretical exposition, we see that the CTT framework makes additional assumptions beyond the classical true score model which makes it so that multiple measurements (either multiple item scores from the same individual or multiple test scores from a group of individuals) can be used to estimate the reliability of a test without requiring repeated measures.

The tradeoff for this nice theoretical result is that the assumptions of either essential tau-equivalence or congeneric measurements have to be tenable. If we claim that the measurements are essentially tau-equivalent, then we are saying that all items load equally on the underlying construct (analogous to equal discrimination). If this is unreasonable, then we may need to settle for congeneric measurements, in which case Cronbach’s alpha only provides a lower bound for reliability.

Another important assumption underlying the use of Cronbach’s alpha is that the variables are continuous. When the variables are dichotomous, the Pearson correlations used to calculate Cronbach’s alpha are known to underestimate the true relationship between items which have different difficulty levels. Consequently, estimate of Cronbach’s alpha is attenuated.

For the HCI, the item responses are hypothesized to reflect an underlying continuous variable (understanding of homeostasis), but the item responses have had an artificial structure imposed on them via dichotomous scoring. Thus, the assumption of continuous variables is violated, and Cronbach’s alpha likely underestimates the true internal consistency of the instrument. The ordinal alpha based on tetrachoric correlations may be more appropriate here.

Unlike the Pearson correlation, the tetrachoric correlation is not computed from the paired values directly. Rather, the tetrachoric correlation assumes that there is a normally distributed latent variable underlying each item. For each pair of items, the tetrachoric correlation is estimated from the observed 2×2 frequency table using the method of maximum likelihood. Thus, the tetrachoric correlation is itself a model which depends on assumptions.

It is useful to report both the coefficient alpha and the ordinal alpha for two reasons. The first reason is the difference in interpretation. The coefficient alpha is an estimate of the internal consistency of the composite scores and reflects the internal consistency of the instrument as it is operationally scored and used. The ordinal alpha is an estimate of the internal consistency of the underlying continuous variables, which reflects the theoretical internal consistency of the instrument if the underlying attribute is normally distributed and could be measured without information loss from the items being dichotomously scored. The second reason for reporting both estimates is that the difference between the estimates itself provides useful diagnostic information. If the ordinal alpha is not much higher than the coefficient alpha, then this suggests that there is little information loss from dichotomous scoring. Conversely, a substantial gap suggests that meaningful information is lost by dichotomous scoring.

The internal consistency of the composite scores is not particularly strong for an instrument which attempts to measure a single construct. The Spearman-Brown prophecy formula can be used to predict the reliability of the instrument if the number of items were to be increased. Note that the Spearman-Brown prophecy formula assumes that the items are parallel. The formula is less accurate for essentially tau-equivalent items and even less accurate for congeneric items. The spearman.brown() function in the {CTT} package can be used to perform calculations using the Spearman-Brown prophecy formula.

According to a frequently cited guideline by Nunnally (1978), a Cronbach’s alpha of .70 or above is acceptable for early stages of research. Additionally, the formula predicts that an alpha of .90 would be achieved with 70 items.

Classical Distractor Analysis

Distractor analysis may be divided into “classical” and “model-based” approaches. This section covers classical distractor analysis, while a later section will cover model-based approaches such as the nominal response model (NRM). Classical distractor analysis primarily involves examining statistics such as the proportions of test-takers who select each distractor and the point-biserial or biserial correlations between each distractor and the total scores. The primary goal of classical distractor analysis is to guide item development by identifying non-functioning or non-discriminating distractors.

Non-functioning distractors are distractors which are selected by a very low percentage of test-takers. A common rule-of-thumb is that distractors which are selected by less than 5% of test-takers are non-functioning. However, an exception to this rule can be made for very easy items. For instance, for a multiple-choice item in which 85% of test-takers chose the correct answer, it is likely that many of the distractors would be considered non-functioning under the 5% rule. However, such distractors are not necessarily problematic, and such items can still have good discrimination and be useful for content coverage purposes.

Non-discriminating distractors are distractors which are equally likely to be selected across the total score range. Good distractors test for misconceptions which are more common in test-takers with a lower total score. As total score increases, test-takers are expected to not have as many misconceptions, and thus should be less likely to select the distractors. If a distractor is roughly equally likely to be selected by all test-takers, no matter their total score, then this suggests that the functioning of the distractor may be unrelated to the construct of interest. For instance, the distractor may be selected due to confusing language or an unintentional cue in the item stem. Typically, the non-discriminating distractors of interest are those which are not also non-functioning, otherwise they would be simply considered non-functioning.

An effective and efficient way to screen for non-functioning and non-discriminating distractors is to examine trace plots, which are also called distractor plots. Distractor plots can be created using the plotDistractorAnalysis() function in the {ShinyDataAnalysis} package. To make the plots look a little nicer, the {ggplot2} and {patchwork} packages are also used.

Optimal Scaling

Thus far, the items have been dichotomously scored by assigning each correct option a score of 1 and each incorrect option a score of 0. However, it is likely that some information is lost by dichotomous scoring. This is because dichotomous scoring treats each incorrect option as having equal value, which is unlikely since the distractors differ in their quality, as seen in the classical distractor analysis above. An alternative is to use optimal scaling, which describes a set of data-driven approaches that assign different scores to each response option by optimizing for some statistical criterion.

A common statistical criterion is to choose scores which maximize the sum of item correlations (the entries in the item correlation matrix). This is equivalent to maximizing the coefficient alpha of the instrument. The corAspect() function in the {aspect} package (Mair & de Leeuw, 2010) can be used to perform optimal scaling. By default, the corAspect() function optimizes for the sum of item correlations (aspect = "aspectSum") and assumes that the variables are nominal (level = "nominal").

In terms of relative fit, the LRT is significant (\(\chi^2\) = 179.33, df = 19, p < .001), which indicates that the more complex model (2PL) fits significantly better than the less complex model (1PL/Rasch). The information criteria all agree with this result, with the 2PL model having a lower AIC by about 141 points and a lower BIC by about 56 points.

In terms of absolute fit, the 2PL model fits better according to every statistic: the M2 is about 199 points lower for the 2PL model, the SRMSR for the 2PL is .047 (compared to .073 for the 1PL), and the TLI and CFI are .915 and .924, respectively. According to conventional guidelines (SRMSR < .05, TLI > .90, CFI > .90), the 2PL model has good fit, while the 1PL model has inadequate fit.

In terms of item fit, a significant result (\(\alpha\) = .05) in the S-X\(^2\) test indicates a misfitting item. Since the S-X\(^2\) test is sensitive to sample size, it is also a good idea to look at the RMSEA for an effect size measure (conventional guideline is RMSEA < .05 indicates good fit). For the 1PL model, items 3, 4, 7, 9, 10, 13, 17, 18, and 19 show statistically significant misfit, and items 7 and 17 show practically significant misfit. For the 2PL model, items 10 and 13 show statistically significant misfit, and no items show practically significant misfit. Thus, the 2PL model has much better item fit than the 1PL (Rasch) model.
